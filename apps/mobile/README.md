# @asocialmedia/mobile

Cross-platform mobile application for asocialmedia built with Expo, React Native, and NativeWind (Tailwind CSS v4).

## Scripts

From the repository root:

- `bun run mob`: Start the Expo development server (port 8082 with Expo Go support)
- `bun run mob:emu`: Launch the default available Android emulator
- `bun run check`: Lint and format across the repo
- `bun run check-types`: Type check across all workspaces including mobile
